# 🌿 StudyNook - Smart Classroom & Study Space Reservation System

StudyNook is a dynamic full-stack web application designed to bridge the structural gap between underutilized campus properties and focused students who require reliable room allocations. Whether you need a quiet corner for deep focus or an empty lecture hall for a study group session, StudyNook lets you discover, book, and manage your ideal space on demand.

🔗 **Live Site URL:** [https://study-nook-weld.vercel.app](https://study-nook-weld.vercel.app) 

---

## ✨ Core Platform Features

* 🎯 **Granular Resource Metrics:** Filter and discover available study locations strictly down to precise floor numbers, maximum seat capacities, specific lighting setups, and individual structural amenities.
* 🛡️ **Enterprise Auth & Cryptographic Token Validation:** Secured completely by state-of-the-art authentication token loops via Better-Auth, ensuring your profile records and booking pipelines are entirely tamper-proof.
* 🔄 **Real-Time Lifecycle Synchronizations:** Instantly search live inventories, dynamically register or manage host property grids, and execute instant database PATCH updates to securely cancel reservations on the fly.
* ⏳ **Flexible Hourly Allocation Structures:** No long-term commitments or administrative red tape. Reserve empty campus corners, group workspace matrices, or lecture halls exclusively for the exact timeline hours you need.
* 📊 **Landlord Pipeline Dashboard:** A centralized control hub for space owners to track active customer states, manage listing arrays, monitor time slots, and optimize vacant campus infrastructure effortlessly.

---

## 🛠️ Built With (Tech Stack)

### Client Side
* **Framework:** Next.js (App Router, Version 15+)
* **UI Core:** React & Tailwind CSS
* **Component Libraries:** DaisyUI & HeroUI (Formerly NextUI)
* **State & Interaction Hooks:** React Hooks (`useState`, `useEffect`, `useContext`)
* **Alert Notifications:** React Hot Toast

### Server & Authentication
* **Backend Network:** Node.js with Express.js REST API
* **Database Engine:** MongoDB (Via native MongoClient pipelines)
* **Security layer:** Better-Auth (with secure JWT validation headers)
